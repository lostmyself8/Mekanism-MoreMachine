# Building the 26.2 branch

Requires Java 25 and NeoForge 26.2.0.93. Use the checked-in Gradle wrapper.

## Mekanism dependency

The port currently compiles against a local Mekanism 10.8.0 snapshot containing core, Additions, Generators and Tools. No third-party binaries are tracked or embedded in the output JAR.

Place the snapshot at `libs/Mekanism-26.2-10.8.0.homebaked-all.jar`, or pass an explicit path:

```sh
./gradlew -PmekanismJar=/path/to/Mekanism-26.2-10.8.0.homebaked-all.jar build
```

The tested dependency includes local fixes from the 26.2 Mekanism port. A fresh checkout and hosted CI need this dependency supplied separately; the branch is not yet independently reproducible from a published Maven coordinate. Do not replace it with a 26.1.2 JAR.

Java compilation runs `verifyMekanismDependency` first so a missing local snapshot produces an explicit setup error, rather than hundreds of missing Mekanism classes. This check does not download the dependency. For GitHub Actions, supply the matching snapshot in a setup step before Gradle runs, using an explicitly selected artifact or published dependency. Re-running the workflow without providing it cannot succeed. Keep the binary outside Git and outside the MoreMachine release JAR.

```sh
./gradlew spotlessCheck build
./gradlew runGameTestServer
./gradlew runClient
./gradlew runData
```

Normal development uses `run/`. Optional mods go in `run/mods/`; isolated GameTests use `run-smoke/mods/`. Tests and their recipes belong to a separate development mod and are excluded from release/source JARs. Optional compatibility JSON lives in `src/main/resources` so datagen does not delete it. Generated assets and standard recipes live in `src/generated/resources`.

Outputs: `build/libs/mekmm-26.2-2.0.0.jar` and `mekmm-26.2-2.0.0-sources.jar`. Install MoreMachine and matching Mekanism on both client and server. `.gitignore` excludes dependencies, run directories, worlds, IDE files, logs and build output.

## Recipes and planting behavior

Large Wind Generator: six steel blocks in the left/right columns, one Wind Generator at top center, one Robit in the middle and one Ultimate Induction Cell at bottom center. The Mekanism Generators condition and recipe are generated by `MoreMachineRecipeProvider`.

All planting recipes retain the seed, sapling or plant template. Energy and nutrient solution are consumed. Stations and factories share the same recipes.

### Croparium (`cp_lib` 5.1.2-beta)

49 optional crop recipes, one product per operation. With only cp_lib installed, 48 load; Everrose additionally requires `everrose`. Products follow the mod's harvest mappings, including intermediate materials. Turtle scute uses the current `minecraft:turtle_scute` identifier, and Sea Heart seeds produce `minecraft:heart_of_the_sea`.

### HBM / NTM (`hbm` 1.0.3)

| Template | Product per operation |
| --- | --- |
| `hbm:plant_flower_cd0` | 1 Mustard Willow Leaf |
| `hbm:plant_flower_cd1` | 2 Mustard Willow Leaves |
| `hbm:plant_tall_cd2` | 3 Mustard Willow Leaves |
| `hbm:plant_tall_cd3` | 4 Mustard Willow Leaves |
| `hbm:plant_tall_cd4` | 5 Mustard Willow Leaves |
| `hbm:plant_flower_weed` | 1 `hbm:plant_flower_weed` |

Leaves use `hbm:plant_item_mustardwillow`. Tall hemp has no planting recipe. Recipes are conditional on HBM and introduce no linkage to its classes.

## Port scope

Migrated machine registries, chemicals, upgrade holders, recipe serializers/caches, JEI displays and render submission to 26.2. Unsupported EMI/CraftTweaker integrations and unused legacy model wrappers are removed. JEI 30.32.0.221 is used for development. Distant Horizons integration still compiles against the available 26.1.2 API and needs testing with a future 26.2 release.

Server smoke tests check machine instantiation, recipe loading, crafting layout, repeated planting, retained templates, and energy/nutrient consumption. Optional mod tests register when their JARs are in the isolated run. Client visuals and full gameplay require manual testing.

## Validation

- `spotlessCheck`, clean `build`, and `runData` pass.
- Without HBM/Croparium: all 13 original required GameTests passed before the additional stamper display regression was added.
- With HBM 1.0.3, Crankshaft 1.6.1 and Croparium 5.1.2-beta: all 41 required GameTests pass, including all five willow stages in both station/factory, flower hemp in both, crop registry checks, the Large Wind Generator grid and stamper display loading. The test-only stamper recipe is finalized during server startup, then every loaded MoreMachine recipe display is checked.
- Release and sources JARs contain the six HBM / 49 Croparium recipes and no test classes/data, bundled dependencies, cache files or logs.
- Full client rendering and gameplay remain for manual testing.

The stamper display regression supplies a test-only stamping recipe so server startup exercises recipe display finalization even without AE2. Before the fix it reproduces the unbound `mekmm:stamper` crash; the display now references the registered `mekmm:cnc_stamper` item.

## Large machine ports and generator rates

Mekanism 26.2's ordinary bounding block proxies pass a vector from the part to its controller. MoreMachine's legacy port layouts describe the vector from the controller to the part; ordinary machines now normalize this at the capability/comparator boundary. The Large Wind Generator's separate proxy already uses controller-relative offsets and is unchanged. This fixes large rotary, chemical infuser, separator, pigment mixer, nucleosynthesizer, solar neutron activator, heat/gas/solar heat generator and tall chemical tank ports, along with the planting station's top port. Existing saved bounding positions do not need rewriting.

Large gas generation uses 64 times the base fuel burn limit, retains each fuel's energy density, and allows automatic output up to twice the maximum generation. With the tested 26.2 fuel data and a full tank:

| Fuel | Burn rate | Generation | Maximum automatic output |
| --- | --- | --- | --- |
| Hydrogen | 16,384 mB/t | 1,310,720 FE/t | 2,621,440 FE/t |
| Ethene | 384 mB/t | 4,620,288 FE/t | 9,240,576 FE/t |

26.2's base ethene rate is an integer 6 mB/t at 12,032 FE/mB, rather than the older fractional 6.4 mB/t. Fuel consumption still scales with tank fullness and available energy space. Fuel attributes are resolved using the level registry, including after loading. GUI power reports actual inserted energy, and this machine's fuel gauge scales the displayed fuel attributes without modifying fuel properties globally. Stored power can still be output after the fuel tank empties. Large heat generation also has a nonzero automatic output limit.

The 41-test suite includes actual bounding block capability queries in four horizontal orientations, rotary vapor→water and water→vapor processing with input/output transfers, full-tank hydrogen/ethene fuel and energy accounting, extraction from the top generator port, and automatic energy transfer to configured receiver cubes. Test receivers have energy input enabled; planting/chemical tank top ports are tested with their corresponding side configuration enabled.
